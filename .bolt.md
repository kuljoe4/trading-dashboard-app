## 2026-05-28 - Risk Aggregation Optimization
**Learning:** Recalculating absolute risk in hot loops for every active trade is inefficient when the data is relatively static.
**Action:** Persist `risk_usdt` on the trade object and update it only when SL changes, allowing O(1) access during metrics aggregation.

## 2026-05-29 - Cockpit Metrics Optimization
**Learning:** Redundant filtering and aggregation of large historical trade sets in the high-frequency tick loop causes unnecessary GC pressure and CPU spikes.
**Action:** Implement lazy-loaded caching for closed trade stats and single-pass O(N+M) aggregation for active variants. Always calculate global PnL from the full active trade set to ensure accuracy during delta broadcasts.

## 2026-05-30 - Realized PnL Persistence Safeguard
**Learning:** Mutating in-memory trade objects with unrealized PnL for UI updates can leak into the database during state changes (e.g., SL adjustments), corrupting realized PnL aggregates.
**Action:** Always zero out 'pnl' and 'pnl_pct' for 'OPEN' trades in the persistence layer before saving. This ensures database queries for realized PnL remain pure.
## 2026-05-30 - [Scanner Short-Circuit]
**Learning:** Performing full signal and score evaluations (volatility, trend) on a large watchlist (50+ symbols) every few seconds is a major CPU sink. Most symbols are inactive (low momentum) at any given time.
**Action:** Implement an early return in the scanner loop for symbols below the configured momentum threshold to achieve a high-efficiency 'gating' mechanism for technical analysis.

## 2026-05-30 - Frontend Data Persistence for Pruned Updates
**Learning:** Over-aggressive backend pruning to save network egress can break the UI if the frontend isn't designed to "remember" state.
**Action:** Implement an explicit merging strategy in the frontend store for "thin" and "delta" updates. Preserve all complex fields (configs, signal statuses) locally so the UI remains robust while the network payload stays minimal.

## 2026-05-30 - Gated Resource Suppression
**Learning:** Maintaining a full market feed watchlist (klines for 50+ symbols) and processing global mini-ticker updates (400+ symbols) when the bot is gated (max trades, sleeping, or paused) with no active trades is a waste of CPU and network egress.
**Action:** Implement `isGated()` logic to aggressively prune the market feed watchlist to zero non-essential symbols and short-circuit mini-ticker processing when idle and restricted. Trigger watchlist updates immediately on gate state changes.

## 2026-05-30 - Config Modal Mobile UX
**Learning:** Mobile browsers (especially iOS Safari) often fail to recalibrate the viewport correctly after a virtual keyboard is hidden if the DOM structure is complex or uses fixed/absolute positioning within a drawer. Sticky headers with backdrop-blur can also cause layout shifts during keyboard transitions.
**Action:** Always use 'inputMode' for optimal keyboards, 'scrollIntoView' on focus, and a 'window.scrollTo' hack on blur to force a layout recalc. Use 'data-vaul-no-drag' on scrollable areas within drawers to prevent gesture conflicts.
