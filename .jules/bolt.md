## 2026-09-27 - [Optimization] Single-Pass Loop Fusion for ScannerOverlay Candidate Ranking
**Learning:** Performing multi-pass array operations (`.sort()`, `Map` lookups, `.map()`, `.filter()`, `.sort()`, `.slice()`, `.sort()`) inside `ScannerOverlay.jsx`'s `filteredResults` `useMemo` hook allocated multiple transient array heap objects and executed multi-pass linear traversals on every high-frequency scanner update frame. Fusing rank assignment, search/range filtering, discovery mode slicing, and final sorting into a single-pass loop pipeline over pre-calculated rank maps eliminated transient array heap allocations and yielded a measured execution speedup.
**Action:** Fuse multi-step filter, map, slice, and sort chains on high-frequency UI collections into a single-pass loop pipeline.
